향수 브랜드의 수요예측과 재고·부자재·고객 데이터를 다시 정의해
밸류체인을 잇고, 현장이 실제로 쓰는 도구로 만든 기록입니다.

## 다룬 문제

- **예측 검증** — 신뢰도가 −61로 표시되던 원인이 단종 품목 한 건이 평균을 148%p 끌어올린 것임을 밝히고, 산식은 그대로 둔 채 정상화
- **데이터 품질** — 대량 구매 한 건이 일판매를 5배로 부풀린 것을 찾아 조합별 상대 절단으로 왜곡만 제거
- **자재 소요** — 부자재를 판매 예측이 아닌 생산 필요량 기준으로 바꿔 거짓 발주 경보 13건 제거
- **출고 최적화** — 요일 판매 지수로 회차별 커버를 환산해 출고를 절반으로 줄이면서 결품률 유지
- **예측 지평** — 롤링 백테스트 5회로 정확도가 아니라 편향이 진짜 위험임을 확인
- **고객 행동** — 회차 전환 퍼널에서 2회차가 결정적 관문임을 찾고 매장별 재구매율 11%p 격차를 정량화
- **경쟁 분석** — 가격은 중위권인데 카테고리 검색 점유율이 0~11%인 구조적 공백을 발견

## 데이터 처리

실제 업무 데이터를 기반으로 하되 브랜드·제품·자재·매장·거래처명은 모두 **가명**으로 바꾸었습니다.
매출과 고객 수는 **지수화**했고, 재구매율·전환율·예측 오차 같은 비율 지표는 분석 논리를 보이기 위해
원본 그대로 두었습니다.
